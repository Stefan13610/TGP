## §8 — Methodological lessons

### Lesson 1: Cycle design — scope category vs scope detail

The four F8 FAILs reflect **scope choice repetition** (all tested kinematics/geometry modifications), not cycle execution defects. **Each cycle was complete within its pre-registered scope.** The pattern is a meta-level signal that scope category was too narrow — not that any individual cycle was wrong.

**For future cycles:** explicit **mechanism category** declaration in Phase 0 prevents accidental category repetition. E.g., "this cycle tests vacuum stress-energy mechanism; OTHER categories (kinematic, clumping, quantum loop) are EXPLICITLY out of scope".

### Lesson 2: Concept paper predictions ≠ cycle work

Appendix E eq. 365 ("Phi-phonon natural DE candidate") was in concept paper from start. Yet no F8 cycle explicitly tested it. This indicates a **gap between concept-paper predictions and cycle pre-registration discipline** — predictions in core docs may go untested for cycles indefinitely if cycle scope doesn't explicitly target them.

**For future:** treat concept paper predictions as **falsifier candidates by default**, requiring explicit rationale to defer.

### Lesson 3: Anti-Lakatos != prohibition of related work

Anti-Lakatos LOCK prevents POST-HOC modification of pre-registered scope/thresholds in response to FAIL. It does NOT prevent:
- Testing OTHER mechanisms with INDEPENDENT pre-registration
- Inheriting LOCKED technical derivations (γ-7 Phase 1 q = √(4πG)·m derivation is LOCKED PASS — inheritable in any cycle)
- Recording forensic analysis like this document

**Distinction:** "γ-7 FAIL → modify γ-7 scope" = forbidden rescue. "Appendix E predicts X → pre-register independent cycle testing X" = legitimate, regardless of γ-7 history.
