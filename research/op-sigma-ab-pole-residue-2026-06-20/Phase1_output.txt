P2 — PROJEKCJA jadra interakcji na fale L=2 (spin-2)
======================================================================
P_2(x) = 3*x**2/2 - 1/2
kontakt phi^4 (M0): proj_{L=2} = int_{-1}^{1} 1 * P_2 dx = 0   => ZERO (kontakt = czysta L=0)
pochodna ~ (k.k') ~ x:   proj_{L=2} = int x*P_2 dx = 0   => ZERO (L=1, nie L=2)
kwadrupol ~ (k.k')^2 ~ x^2: proj_{L=2} = int x^2*P_2 dx = 4/15   => NIEZEROWE (tylko interakcja >=2 pochodne ma L=2)
