    => wykladnik e_s = 0 (kanoniczna)  => alpha=1/2 w s; w Phi=s^2: K~Phi^-1 (=#49!)

[T_B] Sprzezenie geometryczne v2: K_ij=J(phi_i phi_j)^2 * (phi_i-phi_j)^2

[T_C] Czy K_ij=J(phi_i phi_j)^2 wystepuje w mikro H_Gamma?
    H_Gamma bond  : -J s_i s_j         (BILINEARNY w polu)
    geom coupling : +J (phi_i phi_j)^2 (KWARTYCZNY w polu; phi~|s|)
    -> phi_i phi_j ~ |s_i||s_j| ; (phi_i phi_j)^2 ~ s_i^2 s_j^2  (kwartyk bond)
    -> s_i^2 s_j^2  !=  s_i s_j  : RӯNE operatory bond.
    s_i^2 s_j^2 - s_i s_j (test rownosci) = s*(s*(a**2*sxx + 2*a*sx + 2*s) - 2)*(a**2*sxx + 2*a*sx + 2*s)/4  (!=0 => RӯNE)
    WNIOSEK T_C: kwartyczne K_ij (zrodlo alpha=2) NIE jest obecne w eq:B-H.
                 alpha=2 = POSTULAT v2 na poziomie parametru porzadku, nie z H_Gamma.

[T_D] Mapa s -> Phi=s^2 : redefinicja (tautologia) czy coarse-graining?
    dPhi/ds = 2*s  -> zero przy s=0 (nieodwracalna); s i -s -> ta sama Phi (sign-blind)
    => NIE jest redefinicja pola (gubi znak + degeneruje w s=0).
    => crossover przez s->Phi=<s^2> NIE jest tautologia (R1 omijalne TU),
       ALE to dokladnie CG z #49 -> daje alpha_eff=-1/2, nie +2.
