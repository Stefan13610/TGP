# NEEDS (wszystko user-gated; ZERO samowolnych dopisków do core)

Werdykty cyklu: **Q-A-PASS** (sektor samodomknięty bez podłóg/barier)
+ **Q-B-FAIL** (wszystko relaksuje do jednorodnej próżni ψ≡1; zero
nukleacji, zero „pole wybiera granicę"). Drzewo LOCKa §5 dla Q-B-FAIL:
„czysty sektor grawitacyjny nie kreuje — hipoteza kierowana do genezy
poziomu 0 / sprzężenia z materią (osobny LOCK)".

## N1 (z drzewa, kontynuacja PILNEGO N1 poprzednika) — geneza Γ+s_i (poziom 0)

Ten cykl DOMYKA ścieżkę „kreacja z czystej dynamiki pola na poziomie
efektywnym": nawet WŁAŚCIWA para korpusowa (w, V_M9.1''), z poprawnym
krajobrazem (Q-A-PASS), nie wytwarza struktury z szumu, z bumpa
ψ_max=1.30 ani z przeskalowanej sieci — w klasie gradient flow.
Program genezy poziomu 0 (Γ+s_i, MFT substratu) pozostaje główną
niezbadaną drogą „struktury z próżni". [USER-GATE, nowy LOCK]

## N2 (z drzewa) — sprzężenie z materią (osobny LOCK)

Druga gałąź drzewa: kreacja przy granicy metryki jako efekt sprzężenia
sektora grawitacyjnego z materią (L_mat = −(q/Φ₀)ψρ, eq:L-mat-unified;
V_orig pozostaje kanoniczne dla materii — reguła sektorowa sek08a).
Kandydat LOCKa: relaksacja pary (w, V_M9.1'') + źródło ρ (statyczne
lub samouzgodnione); pytanie binarne: czy źródło wciąga pole pod próg
dolny / nad górny (kreacja indukowana), czy tylko deformuje próżnię
(Yukawa-podobnie). [USER-GATE]

## N3 (metodologiczne) — klasa dynamiki

Q-B-FAIL jest wynikiem o RELAKSACJI (gradient flow = dynamika czysto
dyssypatywna; z Q-A-PASS wynik jest a posteriori naturalny: dobry
krajobraz ⟹ spływ do próżni). Kreacja przy granicy mogłaby żyć
w dynamice zachowawczej/2. rzędu (oscylacje przez próg, rezonanse) —
to INNA klasa niż zbadana i wymaga osobnego LOCKa z osobnymi
detektorami zdarzeń. Bez decyzji usera nie twierdzimy niczego o tej
klasie. [USER-GATE]

## N4 (kandydat dopisku core) — domknięcie N3 poprzednika

−γψ³(4−3ψ)/12 jest skończony na granicy i granica jest pod górkę
(Q-A-PASS, sympy); (b) numerycznie: 6/6 biegów regularnych vs 10/10
BREAKDOWN hybrydy. Kandydat dopisku core (sek08a, przy

zweryfikowana relaksacyjnie jako samodomknięta (op-metric-pair-M911,
